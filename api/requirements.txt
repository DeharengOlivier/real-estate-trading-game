# passes a `sort` argument down to the bulk builder, and mongomock 4.3.0, the

# raises TypeError and the quarter advance cannot be tested at all. Motor 3.7
# supports 4.9 through 4.10, so this is a supported pairing, not a workaround
# on the driver's behalf.
