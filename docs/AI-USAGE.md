### Quality of AI-generated Tests

**Strengths:**

## Comments and Documentation

### Python Docstrings

**Usage:**
- Type `"""` after a function
- Copilot suggests a complete docstring
- Includes params, returns, raises

**Generated example:**
```python
def get_property_current_price(db, property, current_quarter):
    """
    Calculate current price of a property based on market index.

    Args:
        db: MongoDB database instance
        property: Property document
        current_quarter: Current game quarter (e.g. "2024-Q2")

    Returns:
        float: Calculated price
    """
```

**Quality:**
- 90% correct on the first suggestion
- Minor adjustments for precision
- Google/NumPy style respected

### Inline Comments

**Pattern:**
- Write a descriptive comment
- Copilot suggests the matching code
- Validate or adjust

**Example:**
```python
# Calculate total cost including 2.5% fees
total_cost = price * 1.025
```

**Effectiveness:**
- Self-documenting code
- Fewer logic bugs
- Better maintainability

```javascript
      setProperties(data.items);
    } catch (error) {
      setError(error.message);
    }
  }
  fetchProperties();
}, []);
```

## Limits and Precautions

### What the AI does well

- Boilerplate code
- Standard patterns
- Documentation structure
- Basic tests
- CSS styling
- Python type hints

### What the AI does poorly

- Complex business logic
- Advanced security
- Performance fine-tuning
- Overall architecture
- Design decisions

### Validation Required

**Always check:**
- That the business logic is correct
- That there are no security flaws
- That performance is acceptable
- That the code is idiomatic
- That tests cover real cases

**Never:**
- Copy-paste without understanding
- Trust blindly
- Ignore warnings
- Skip code review

## Effective Prompts

### Structure of a Good Prompt

**Include:**
- Project context
- Language/framework
- Expected result
- Specific constraints

**Example:**
"In a FastAPI API with MongoDB, create an endpoint to sell a property. Verify that the user owns the property, compute the current price, apply a 2.5% fee, update the cash, and create a trade record."

**Bad example:**
"Function to sell"

### Iteration

**Approach:**
1. General prompt
2. Refine with details
3. Ask for optimizations
4. Request tests

**Iteration example:**
- "FastAPI endpoint to buy a property"
- "Add a sufficient-cash check"
- "Use a MongoDB transaction for atomicity"
- "Generate tests for this endpoint"
